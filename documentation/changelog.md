# Changelog

## [1.2.0] - 2023-10-15
### Added
- **Profile Management Enhancements**:
  - Users can now view their complete profile including Name, Email, Registration Date, and Account Status, with the capability to edit the Name.
  - Real-time validation added for Name field changes; backend validation mirrors frontend logic to ensure robust security against unauthorized or malformed input.

### Changed
- **Audit and Logging**: Enhanced logging features to capture audit trails for Name changes, augmenting compliance and security posture.
- **Email Notification System**: Integrated new notifications for confirming Name changes, providing users with immediate feedback on updates to their profile.
- **Performance Optimizations**: Improved page load times to meet the sub-2 second performance criteria.

### Fixed
- Addressed multiple accessibility issues to ensure WCAG 2.1 AA compliance, enhancing overall user experience for individuals with disabilities.
- Fixed potential security vulnerabilities related to XSS within profile inputs.
