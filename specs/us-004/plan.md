This story will feature backend changes to manage a new email verification field and logic in the registration and authentication process. First, database modifications are required to accommodate email verification tokens. Then, existing user registration flows need to be updated to send a verification email via SendGrid (using `BACKEND/scripts/test-sendgrid.ts` for sending). We'll also implement endpoints in `BACKEND/src/routes/activation.routes.ts` to handle verification link clicks by updating the user's verification status in the database. Lastly, introduce logic to intercept users' access attempts with unverified emails on critical routes. Documentation updates are required in `README.md` to include details on this process.
