The Email Verification Process initiates when a user registers an account. The system sends a verification email with a unique link, which must be clicked by the user to activate their account. This process ensures that only users with verified email addresses gain full access to services. Should the user attempt to access certain profile features with an unverified email, access is restricted until verification is complete. Acceptance criteria include successful sending of verification emails upon registration, activation of the account once the email link is clicked, and restriction of access for unverified emails. Out of scope are UI design changes and email template design, which depend on another team's assets and services.
