# Currency Service Documentation

## Overview
This document provides insights into the newly implemented real-time currency rate display feature.

## New Features
- **Real-time Currency Display**: Displays live updates of currency rates for over 50 currencies.
- **User Interface Enhancements**: Integrates seamlessly into current transaction flows.

## Technical Details
- **API Integration**: Utilizes a dedicated service to fetch currency rates from external providers.
- **Caching**: Implements caching mechanisms to optimize performance.

## Deployment
- Ensure that the CI/CD pipeline is updated with the latest build and deployment scripts.

## User Guidelines
- Users can access the currency rates on the main dashboard after login.
