### Modernization Constitution
1. **Evidence-based:** Changes and verification must use outputs from code graph, dependency, complexity, and dead code tools.
2. **Safety-first:** No deployment unless full regression and defined UAT processes pass for high-complexity areas.
3. **Cleanup:** Remove or refactor true dead code only after graph-confirmed and regression-tested.
4. **Transparency:** Report all findings, test runs, dead code validations, and remaining issues post-upgrade.
